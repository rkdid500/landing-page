# 랜딩페이지

스마트폰(갤럭시 · 아이폰) 모델별 월 납부액과 혜택을 한눈에 보여주고, 이름·연락처로 상담 신청을 받는 단일 페이지 랜딩페이지입니다.
빌드 도구 없이 `index.html` 하나로 동작합니다.

## 구성

| 영역 | 설명 |
|---|---|
| 첫 화면 | "최대 ○○만원" 대형 숫자 + 핵심 3가지 + 신청 폼 |
| 한눈에 보는 혜택 | 번호이동 지원금 / 비밀지원금 / 사은품 / 제휴카드 (데이터에서 자동 계산) |
| 모델별 출고가 할인 | 브랜드 탭, 모델별 출고가·지원금·할인율·실구매가 |
| 사은품 | 정가 → 무료 |
| FAQ / 푸터 | 자주 묻는 질문, 사업자 정보 |

상단바(브랜드명 + 대표번호)는 스크롤해도 고정되며, 모바일에서는 하단 고정 바가 나타납니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 로컬 서버가 필요하면:

```bash
node serve.js   # http://localhost:5173
```

## 내용 수정

`index.html` 하단 `<script>` 맨 위의 `CONFIG` 한 곳만 수정하면 됩니다.

| 항목 | 설명 |
|---|---|
| `brand`, `phone`, `kakaoUrl` | 브랜드명, 대표번호, 카카오톡 채널 링크 |
| `models` | 모델별 `list`(출고가) / `support`(번호이동 지원금 합계) / `final`(최종 기기값) / `carrier`(통신사) / `join`(가입 유형) |
| `plans` | 요금제 정보 (번호이동 지원금 합계 방식에서는 화면에 표시하지 않음) |
| `gifts` | 사은품명 / 정가 |
| `heroMax` | 첫 화면 "최대 ○○만원" 고정 숫자(만원, 카운트업 후 이 값으로 고정). `null`이면 모델 데이터로 자동 계산 |
| `months`, `selectRate`, `cardMonthly`, `dataDate` | 할부 개월, 선택약정 할인율, 제휴카드 월 할인, 지원금 확인 기준일 |
| `company`, `ceo`, `bizno`, `mailorder`, `address`, `email`, `privacyOfficer` | 푸터 사업자 정보 |
| `formEndpoint` | 신청 데이터를 받을 URL (JSON POST). 비우면 데모 모드로, 어디로도 전송되지 않습니다. |

### 금액 데이터 기준

- **모델 · 출고가 · 번호이동 지원금(`support`) · 최종 기기값(`final`) · 통신사**: SAKD 사이트 상품 데이터(`js/mobile-products.js`)를 그대로 옮겼습니다. 가입 유형은 **번호이동** 기준이며 지원금은 합계 한 줄로 표시합니다.
- 실구매가는 소스의 `final`(최종 기기값)을 사용하고, 할인율은 (출고가 − 실구매가) ÷ 출고가 입니다. 월 납부액은 표시하지 않습니다.
- 통신 3사 공식 지원금 조회 페이지(기기변경 기준)와는 값이 다를 수 있습니다. 지원금은 요금제·가입 유형·시점에 따라 수시로 바뀌므로 **게시 전과 변경 시마다 재확인**하세요.
- 비밀지원금은 `hideSecret: true` 이면 금액 없이 "상담 후 안내 @" 와 총 혜택 옆 `+@` 로만 표시됩니다.
- 사은품(`gifts`), 제휴카드(`cardMonthly`)는 판매점 조건이라 예시값입니다. 실제 값으로 교체하세요.

## 색상 톤

URL 뒤에 `?theme=` 를 붙여 미리 볼 수 있습니다. 기본값은 `deep` 입니다.

| 값 | 느낌 |
|---|---|
| `deep` (기본) | 깊은 남보라 + 라임 포인트 |
| `purple` | 선명한 보라 + 핑크 빛 |
| `light` | 연한 라벤더 + 진보라 숫자 |
| `orange` / `coral` / `green` | 주황 / 코랄 / 초록 |

기본 톤을 바꾸려면 `<html lang="ko" data-theme="deep">` 의 값을 바꾸세요.

## 신청 데이터

폼 제출 시 아래 형태의 JSON을 `formEndpoint`로 전송합니다.

```json
{
  "name": "홍길동",
  "phone": "010-1234-5678",
  "model": "갤럭시 Z 플립7",
  "quote": { "model": "...", "plan": "...", "method": "...", "monthly": 0, "benefit": 0, "list": 0 },
  "page": "/", "referrer": "", "submittedAt": "ISO8601",
  "utm": { "utm_source": "...", "utm_campaign": "..." }
}
```

유입 경로 추적을 위해 `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content` 값을 함께 수집합니다.

- [x] 사업자 정보(상호·대표자·사업자등록번호·통신판매업 신고번호·주소·이메일)는 sakd.co.kr 기준으로 입력됨

- [ ] `formEndpoint` 연결 및 접수 테스트
